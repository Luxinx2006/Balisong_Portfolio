# Personal Development Portfolio

Static site — just `index.html` and `images/profile.jpg`.

## Put it on GitHub Pages
1. Create a new repo (e.g. `my-portfolio`) and upload this whole `portfolio` folder's contents to the root.
2. Repo → Settings → Pages → under "Build and deployment", set Source to **Deploy from a branch**, branch `main`, folder `/root`.
3. Save. Your site will be live at `https://<your-username>.github.io/<repo-name>/` in a minute or two.

## Editing later
All content lives directly in `index.html` (no build step). Open it in any text editor, edit the text inside the `<section>` blocks, and push your change.
